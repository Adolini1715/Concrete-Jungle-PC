Fonts for the Portuguese (Brazil) translation: the game's four font atlases twice as tall, the
top half the Sharp UI atlas (packs/sharp-ui), the bottom half accented letters drawn from
Liberation Sans (SIL Open Font License), made by tools/art/lang_fonts.py. The translation itself
(lang/pt-br/text.txt) is a separate download in the launcher (Texture Packs), which brings these
fonts with it.
