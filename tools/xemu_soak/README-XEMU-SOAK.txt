XEMU RECORDER (Predator: Concrete Jungle)
=========================================

Records you playing the real game in xemu so the PC port can be checked
against it: picture, sound, controller and what the game is doing.

How to use
  1. Double-click XEMU-SOAK.bat.
     It opens xemu by itself. If xemu is already open, it either records it
     or asks to reopen it (click OK).
  2. Start Predator: Concrete Jungle in xemu and play with a controller.
     Press F9 at moments worth comparing with the PC build (scripted
     events, cutscene beats, distinctive enemy reactions) and when xemu
     itself glitches (graphics, sound, stutter), so it is not taken as
     the game's behaviour. F9 also saves a memory snapshot; F7 saves just
     a snapshot. Save states are fine: press F9 right after loading one.
  3. Close xemu when you are done. The recording stops by itself.

That's it. Recordings go to Downloads\pcj-xemu-recordings.

If it ever says it cannot find xemu: open xemu the normal way, then
double-click XEMU-SOAK.bat and click OK. It remembers where xemu is after that.

One recording per chapter works best (memory snapshots are 64 MB each,
up to 60 a session, in the recording's mem folder).
